# Vaibhav Nawal — Personal Portfolio

Personalized portfolio for GitHub Pages.

## Files
- `index.html` — website
- `style.css` — responsive styling
- `resume.pdf` — Vaibhav's resume
- `project-report.pdf` — IIT Bombay deep-learning project report

## Deploy
1. Create a public GitHub repository named `vaibhav8nawal.github.io`.
2. Upload all four files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Visit `https://vaibhav8nawal.github.io`.
